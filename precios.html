Crear mi clave en GitHub

  2. El nombre, la duración y el permiso ya vienen puestos. Solo baja hasta Repository access, elige Only select repositories y en la lista marca le-parfum.
  3. Toca Generate token al final (y otra vez si te pide confirmar).
  4. Copia el texto que empieza con github_pat_, vuelve aquí, pégalo abajo y toca «Guardar en este teléfono». GitHub lo muestra una sola vez.
